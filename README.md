# Obesity Estimation Based on Eating Habits and Physical Condition

### Machine Learning Classification Project

---

**Project Overview**

This project focuses on estimating obesity levels based on individuals' eating habits, lifestyle choices, and physical conditions using Machine Learning techniques.

**Project Objectives**
- Analyse eating habits and lifestyle patterns.
- Explore the relationship between physical activity and obesity levels.
- Apply Machine Learning classification algorithms.
- Compare model performance using evaluation metrics.
- Predict obesity categories based on the given features.

**Dataset Information**

- Dataset: Estimation of Obesity Levels Based on Eating Habits and Physical Condition
- Total Records: 2,111
- Input Features: 16
- Target Variable: `NObeyesdad`
- Classification Type: Multiclass Classification
- Target Categories: 7

**Algorithms Used**
1. Logistic Regression
2. Decision Tree Classifier
3. Random Forest Classifier

- Python
- Jupyter Notebook
- Pandas
